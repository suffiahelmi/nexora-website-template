# NEXORA — Autonomous Cloud Intelligence & Enterprise SaaS Template

**NEXORA** (Product 03) is a commercial Next.js + TypeScript + Tailwind CSS website template engineered for next-generation software, cloud infrastructure, distributed systems, and developer-tooling startups.

## Aesthetic & Design System
- **Background Palette**: Midnight Navy (`#060913`, `#0B1021`) & Deep Charcoal (`#111827`, `#161F33`)
- **Primary Accents**: Electric Blue (`#0066FF`) & Cyber Cyan (`#00D4FF`)
- **Secondary Accent**: Neon Lime (`#CCFF00`)
- **Typography**: `Space Grotesk` (Geometric Display), `Plus Jakarta Sans` (High-Contrast UI Sans), `JetBrains Mono` (Telemetry & Code)

## Scripts
```bash
npm run dev        # Start local development server
npm run lint       # Run ESLint validation
npm run typecheck  # Run TypeScript compiler verification
npm run build      # Create production build
npm run start      # Run production server
```
